# Ballance Reversed 🧩

**Ballance Reversed** — это модификация кампании для классической игры *Ballance* (2004 г.), которая полностью переворачивает исходный прогресс уровней!

Вместо того, чтобы начать с базового уровня обучения, вы сразу погружаетесь в хаос **Уровня 13** и продвигаетесь обратно к **Уровню 1**.

---
## 🌟 Ключевые особенности

* **Обратная кампания:** Проходите уровни в обратном порядке (13 → 12 → 11 → ... → 1).
* **Все уровни разблокированы:** Каждый уровень доступен с самого начала.
* **Классический опыт Vanilla:** Чистый оригинальный игровой процесс с нетронутой физикой, звуковыми эффектами и графикой.
* **Ностальгический профиль:** Включает в себя знаменитый профиль игрока по умолчанию «Fluffer» (в локализованных версиях известный как «Гluffer»).

---

## 📥 Установка

1. Убедитесь, что у вас установлена чистая копия *Ballance*.
2. Загрузите последнюю версию из раздела [Releases](../../releases).
3. Извлеките и скопируйте файлы в основную папку установки Ballance, перезаписав их при появлении запроса.
4. Запустите игру и наслаждайтесь обратным испытанием!
